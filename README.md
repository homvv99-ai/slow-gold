## ما هذا؟

آلةٌ منهجية تتداول ذهبًا (PAXG/USDT) بإطارٍ يومي:
- **داخل السوق (LONG)** حين يصحّ الاتجاه
- **خارج السوق (FLAT)** حين لا يصح — سيولةٌ تنتظر

لا توقّع، لا توصيات، لا وعود. فقط **سطرٌ موقعٌ كل فجر** يوثّق القرار.

## الدستور

1. **لا وعود ربح** — الماضي لا يعد بالمستقبل
2. **الدفتر موقع** — كل سطرٍ مربوطٌ بتجزئة ما قبله (سلسلة)
3. **أقل سلطة** — البوت مشرفٌ بصلاحية نشرٍ واحدة فقط
4. **الخطأ يُسمّى** — يُصلح علنًا ويُوثّق في السجل
5. **ليست نصيحة استثمارية** — التداول ينطوي على مخاطر مالية
